# Видео: профили пользователей

Цель — показать, что агент отвечает каждому пользователю в его стиле без напоминаний, хранит личный разговор и восстанавливает выбор после перезапуска. В сценарии четыре запроса к модели; `/profile-init`, `/profile`, `/profile load` и `/exit` API не вызывают.

Условия: полная история без стратегии (`AGENT_CONTEXT_STRATEGY=`), prompting `direct` (значение по умолчанию), модель из `.env` проекта, отдельный временный каталог. Ключ загружается из `.env` через `--env-file` и в команды не попадает. Переменные, заданные в команде запуска, важнее значений из `.env`; пустой `AGENT_MAX_INPUT_TOKENS=` отключает бюджет.

## Подготовка

Из корня проекта с настроенным `.env`, Node.js 24+:

```bash
export AGENT_ROOT="$PWD"
```

```bash
export DEMO_DIR="$(mktemp -d "${TMPDIR:-/tmp}/agent-profile-demo.XXXXXX")"
```

```bash
cd "$DEMO_DIR"
```

Функция запуска действует в текущем окне терминала:

```bash
agent() { AGENT_CONTEXT_STRATEGY= AGENT_MAX_INPUT_TOKENS= node --env-file="$AGENT_ROOT/.env" "$AGENT_ROOT/src/index.ts" "$@"; }
```

```bash
agent
```

Показать: `Пользователь: без профиля`, приглашение `без профиля > `.

## Шаг 1. Профиль Макса и вопрос о кешировании

```text
/profile-init
```

Ответы на вопросы опроса, по одной строке:

```text
Макс
```

```text
На ты, простыми словами, ответ списком из 3–5 пунктов
```

```text
Без эмодзи и без кода
```

```text
Backend-разработчик, изучаю AI-агентов
```

Показать: итог «Профиль «Макс» сохранён», `Пользователь: Макс`, приглашение `Макс > `.

Запрос 1:

```text
Объясни, что такое кеширование.
```

Ожидается: обращение на «ты», простой язык, короткий список без эмодзи и кода.

## Шаг 2. Профиль Владимира и тот же вопрос

```text
/profile-init
```

```text
Владимир
```

```text
На вы, технически точно, ответ таблицей
```

```text
Без эмодзи, предположения помечать явно
```

```text
Архитектор высоконагруженных систем
```

Показать: приглашение `Владимир > `.

Запрос 2:

```text
Объясни, что такое кеширование.
```

Ожидается: обращение на «вы», технические термины, таблица. Разговор Макса в запрос не попадает.

## Шаг 3. Возврат к Максу

```text
/profile load Макс
```

Показать: `Пользователь: Макс`, приглашение `Макс > `.

Запрос 3:

```text
А что такое инвалидация кеша?
```

Ожидается: снова стиль Макса; «кеш» понятен из его разговора на шаге 1.

## Шаг 4. Перезапуск

```text
/exit
```

В том же терминале — тот же `$DEMO_DIR`:

```bash
agent
```

Показать: сразу `Пользователь: Макс` и приглашение `Макс > `.

```text
/profile
```

Запрос 4:

```text
Что мы уже обсудили и что стоит изучить дальше?
```

Ожидается: список в стиле Макса по кешированию и инвалидации, без упоминания таблицы Владимира.

```text
/exit
```

## Сводка

| Запрос | Пользователь | История перед запросом | Ожидаемое оформление |
| --- | --- | --- | --- |
| 1 | Макс | пусто | на «ты», простой список |
| 2 | Владимир | пусто | на «вы», таблица |
| 3 | Макс | ход 1 | на «ты», простой список |
| 4 | Макс после перезапуска | ходы 1 и 3 | на «ты», простой список |

Для наглядности хранения после записи можно показать файлы, API они не вызывают:

```bash
cat "$DEMO_DIR/.agent-profiles.json"
```

```bash
ls -a "$DEMO_DIR/.agent-users"/*
```

Каталог у каждого пользователя свой; имя — SHA-256 от идентификатора.

## Ожидаемое и фактическое

Таблица описывает ожидаемое поведение модели, а не гарантированный текст: модель может нарушить оформление или перефразировать ответ. Детерминированно проверяются состав запросов и состояние приложения в автотестах: `tests/profile-requests.test.ts`, `tests/session.test.ts`, `tests/cli.test.ts`, `tests/cli.e2e.test.ts`.

Прогон с реальной моделью при подготовке сценария не выполнялся; фактические ответы фиксируются после записи видео. Команды и последовательность шагов проверены 16 сентября 2026 с подменённым API (`tests/support/mock-api.ts`): активный пользователь, приглашения, `.agent-profiles.json` и истории пользователей после каждого шага совпали с таблицей.
