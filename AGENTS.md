# AGENTS.md

## Что это

`my-first-agent` — stateful CLI-агент для DeepSeek через OpenAI-совместимый SDK. Линтер и форматтер — Biome, тесты — Vitest, CI — GitHub Actions.

## Архитектура

`src/index.ts` собирает приложение: окружение, SDK, `Agent` и CLI. `src/cli.ts` работает только с интерфейсом `AgentPort` и не знает формат API.

`src/agent.ts` владеет конфигурацией, историей и расходом токенов. `respond()` собирает сообщения, вызывает LLM, валидирует ответ и сохраняет успешный ход. `reset()` очищает историю и статистику, сохраняя конфигурацию.

Настройки одного агента находятся в `AgentConfig`. Сравнение моделей, повторные прогоны и внешние judge относятся к orchestration и не должны попадать в `Agent`.

## Инварианты

- В истории хранятся только успешные пары `user`/`assistant`.
- Системный промпт собирается заново для каждого вызова и в историю не записывается.
- Meta-промпт остаётся внутренним и не попадает в историю диалога.
- Usage пустого ответа учитывается; ошибка транспорта без ответа usage не меняет.
- Параллельные вызовы одного stateful-агента запрещены.
- API-ключ не входит в `AgentConfig` и не возвращается в `AgentResult`.

## Команды

```bash
npm install
npm run dev
npm run dev -- "вопрос"
npm run lint
npm run typecheck
npm test
npm run test:coverage
npm run build
```

Нужен Node.js 24+. Относительные импорты используют расширение `.ts`; сборка переписывает его в `.js`.

Тесты не вызывают внешний API. `tests/support/fake-client.ts` проверяет параметры SDK, e2e использует подменённый `fetch`.
